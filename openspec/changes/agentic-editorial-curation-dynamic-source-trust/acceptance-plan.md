# V1.1 Product Acceptance Plan

## Contract and Candidate Rules

冻结增量为 **10 项 PAT-V11-01–10**；每项是必须满足的产品观察。最终报告必须绑定同一个集成 candidate SHA、产品契约 revision、环境、时间和 evidence 索引，逐项记录 PASS / FAIL / NOT-RUN。工程套件可以直接支持被证明的观察，但测试总数或构建成功不能代替逐项裁决。AE 只验收、不修代码；任何真实 FAIL 返回负责的 Implementer，修复后集成新候选并重跑受影响项。

V1 的 49 项验收保持原历史候选身份，不修改旧报告、旧 OpenSpec change 或 evidence 分支。本次仅创建新的 V1.1 和受影响 V1 回归报告。表中的 V1 案例观察引用旧冻结文本，不重新定义含义。所有新 PAT 与列明的 V1 回归 PASS 后，PM 方可声明本增量 PRODUCT_ACCEPTED。

一次产品 flow 可同时提供多个 PAT 证据；可以复用当前最终候选已有的直接工程/组件证据，不因其为组件测试就自动 PASS，也不要求重复同一观察。候选变化后先按改变的观察面列出证据有效性；不得将旧 candidate SHA 的未验证日志冒充新候选运行。

## Common Evidence

- 保存候选 SHA、base main SHA、契约 revision、实际偏好、开始/结束时间、trigger、Issue/attempt identity。
- 候选运行前生产代码的出版者名称/来源/搜索提示列表快照及未预列域名核对。测试 fixture、文档或本轮发现后 trace 中的域名不属于生产来源名单。
- 全文依据包含实际来源/可访问 URL、canonical、publisher 身份信号、完整性/英文正文结果、正文词数/段落数或散列。不得在 GitHub 证据中公开 API key、个人配置或未经许可保存/传播整篇文章。
- 语义证据包含契约版本、provider/model 标识、候选 ID、实际有界内容输入摘要/散列、合法结构决定及结果关联。对实际模型调用记录成功/失败凭据；可以脱敏请求响应，不能删去判断内容的决定性证据。
- 实时网络与模型案例各至少一次。PAT-V11-03 必须使用真实 provider；PAT-V11-06 必须真实联网宽泛搜索、没有完整候选 URL 输入。可由一个真实 collection 同时满足两者，但只有其候选对照足以证明 03 时才合并裁决。

## New PATs

| Case | 冻结观察和最小动作 | 决定性 PASS 证据 |
|---|---|---|
| PAT-V11-01 | 提供或发现一个生产来源/名称列表外的真实英文出版者文章；通过实际核验后，在语义认可且硬约束允许的情形处理入选 | 域名缺席快照、实际文章提取/来源/完整性证据、FULL_TEXT 资格及成功入选路径；不存在因域名未知而 EXTERNAL_ONLY 的决定。实际抓取必须真实；可用受控语义批准单独证明入选通路，真实语义能力另由 03 证明 |
| PAT-V11-02 | 对未知域名分别提供元数据冲突、无法解释的跨来源 canonical、摘要/不完整正文，再给出模型要求接纳的输出 | 每个输入均无 FULL_TEXT 或篇数贡献；理由指向对应客观失败，模型不能覆盖；fixture 可用于稳定重现故障 |
| PAT-V11-03 | 以三篇已核验的同主题候选和两篇阅读位置调用真实模型：普通重复事实报道的主题关键词更多；另两篇提供更强解释及独立视角，且共同符合时长/难度 | 实际 provider 请求/响应绑定候选；分析与独立视角入选，普通重复报道不占位；理由提及实际内容的解释或视角贡献，不能只是出版者名或关键词数。保留 input/output 与 final selection 对应关系 |
| PAT-V11-04 | 对同一事件的独立报道、原创分析与其中一篇复制/转载一起策展，前两篇满足偏好 | 两篇独立文章可共同入选并各有归属/贡献依据；复制品不另占位；共享事件不触发去重。可与 03 或 V1 RC-26–28 共用运行 |
| PAT-V11-05 | 对实际结构验证入口提供未知版本、遗漏/重复/未知 ID、非法值，以及 URL/来源/FULL_TEXT 等越权字段 | 无效响应不能发布文章或标 COMPLETE；越权字段拒绝或明确阻断；候选安全/来源/估值事实不变；验证失败记录与 08 一致 |
| PAT-V11-06 | 保存偏好为完整输入执行真实 collection；记录运行前生产名单与宽泛查询 | 至少一个不限定域名的真实搜索及其结果；至少一个未预列出版者进入候选宇宙，并完成全文核验或得到语义决定；只有旧名单来源不算 PASS。禁止用完整预装 URL 列表模拟发现 |
| PAT-V11-07 | 运行原安全边界场景并尝试通过模型输出引入/提升被拒候选 | 私网/回环/IPv6 本地、credential URL、redirect、DNS 多地址/重绑定、代理固定 IP/NO_PROXY 保护继续通过；无 Agent 绕行请求；来源/访问/正文失败不变 FULL_TEXT。可直接采用覆盖这些调用路径的候选绑定工程证据 |
| PAT-V11-08 | 在有旧 Issue/进度时分别模拟无配置、临时 provider 失败、无效结构；用受控时钟观察自动重试 | 失败和语义状态可见，无确定性伪装成功、无未经批准的新交付；旧归档/进度不变；scheduled 总尝试最多 3 次，永久失败不无限重试；无需等真实日历时间 |
| PAT-V11-09 | 对真实 Agent 新交付文章查看可选详情/trace，重启 Reader/服务后再检查，同时读取一条无新字段的 V1 历史记录 | 相同 article identity 的简短理由、主题适配/占位依据、贡献类型和契约/决定关联仍可查；来源事实保持；V1 历史仍可读且没有伪造理由。无需常驻 UI 新标签 |
| PAT-V11-10 | 使用有效语义决定尝试超预算、难度不符或不足数量的组合，以及模型拒绝但能凑数的候选；另提供可满足全部目标的组合 | 只从合格且批准新增候选形成 Issue；精确篇数、主题、难度与 70%–100% 时长满足才 COMPLETE；不满足则明确 PARTIAL/NOT_DELIVERED 与缺项，100% 上限、估值不被模型覆盖；可复用 RC-12–14 |

## Affected V1 Regression

必须在本次最终候选复核以下 **17 项** V1 观察。可共享候选绑定 fixture、组件/服务运行、真实网络及一个浏览器 flow；不要求 17 个独立端到端会话。原案例文本仍以 `../add-sayit-reader-plugin/specs/` 为准。

| V1 Case | 受影响原因与保留观察 | 建议复用 |
|---|---|---|
| PAT-RC-07 | 发现入口/策展阶段改变；仅偏好输入的真实查询、候选、核验及选择 | V11-06 实时运行 |
| PAT-RC-08 | 候选送入 Agent 前仍对同文/转载/镜像去重，只占一位并记录归属 | V11-04 |
| PAT-RC-09 | 来源资格门移除后，原文不可访问仍区分 Original/Accessible，无法核验副本仍排除 | V11-02 与来源恢复 fixture |
| PAT-RC-10 | 独立替代文章仍使用自身出版者/访问链接，并保留原失败原因 | 同一来源恢复 fixture |
| PAT-RC-11 | 新语义网络阶段也可能失败；attempt 状态/trigger 诚实，旧归档保留 | V11-08 与现有离线工程证据 |
| PAT-RC-12 | 语义否决造成短缺时显示 PARTIAL/NOT_DELIVERED 和真实数量/时长 | V11-10 |
| PAT-RC-13 | COMPLETE 仍符合主题、精确篇数、难度和 70%–100% 时长 | V11-10 |
| PAT-RC-14 | 供给不足不降低偏好或补入不合格文章 | V11-10 |
| PAT-RC-15 | 未知摘要/搜索片段仍不得计全文，继续发现或报告短缺 | V11-02 |
| PAT-RC-16 | 消失页面不得交付全文，只能用核验版本/替代或报告短缺 | 来源恢复 fixture |
| PAT-RC-18 | Agent 需要看到已有文章重叠；scheduled 只为同一 PARTIAL Issue 增添合格非重复文章 | collection 服务的受控时钟补齐 flow |
| PAT-RC-26 | 同一事件的独立报道和分析可各自参与/进入 Issue | V11-04 |
| PAT-RC-27 | 无独立新增内容的高相似文章仍拒绝且记录近重复判据 | V11-04 与现有 shingle fixture |
| PAT-RC-28 | 共享事件/实体本身不去重 | V11-04 |
| PAT-RH-09 | 新来源 FULL_TEXT 必须在 Reader 中展示可连续阅读正文 | V11-01/06 交付文章的一个浏览器 flow |
| PAT-RH-12 | 未核验/外链候选仍诚实显示且不占完整篇数 | 同一浏览器 flow |
| PAT-RH-15 | 文章新增理由/持久化字段不能破坏 Regenerate 旧 edition/进度保留 | V11-09 加现有 Regenerate 候选绑定断言 |

其余 V1 PAT 的调度算法、主输入/结果/会话、词典/IPA/Listen/interpretation、基础偏好与位置行为未因本产品增量改变，保留历史验收并运行正常工程套件回归。若实现实际修改这些观察面，AE 在新报告补列受影响旧案例并执行原含义；这不是新增 PAT 或重写旧契约。

## Execution and Reporting

PM 冻结并维护产品权威；Implementer 只修实现；Integrator 固定一个最终候选；AE 独立收集、复用和裁决证据。最终报告机械列出 10 项新 PAT 与 17 项已知受影响 V1 PAT 的 PASS/FAIL/NOT-RUN，总数分开统计；任何扩大的回归集合需说明实际改动原因。每个未 PASS 案例写明缺失观察或真实阻塞。PM 声明仅覆盖 V1.1 增量及本轮回归，不改变 V1 历史报告。
