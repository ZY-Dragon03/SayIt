# Spec Delta

## Purpose

本能力在确定性文章核验后使用真实 Editorial Agent 进行有界语义策展，为用户选择有阅读价值且保留独立观点的英文文章，并保存可解释、可验证的编辑决定，同时维持 Daily Issue 的原有履约规则。

## ADDED Requirements

### Requirement: 真实 Agent 基于内容作出编辑判断

系统 SHALL 在安全提取、全文核验和文章去重后、最终 Daily Issue 选择前调用真实模型能力。Agent SHALL 获得有界的文章内容证据、来源/标题、时间（已知时）、长度/难度、重复关系与用户偏好，并返回主题适配、编辑价值、分析深度、新颖性、重叠和观点贡献判断。固定来源优先级或关键词计数 SHALL NOT 代替语义决定。

#### Scenario: PAT-V11-03 真实语义策展选择阅读价值与独立视角
- **GIVEN** 三篇已核验、符合硬性偏好的同一宽主题候选分别为重复常见事实的简短报道、有较强因果解释的分析、具有实质独立观点的文章；后两篇可共同满足两篇阅读目标，而普通报道具有更多主题关键词
- **WHEN** 最终候选用现有配置的真实模型执行语义策展
- **THEN** 选择分析与独立观点文章，普通重复报道不占本次有限阅读位置；每项理由指向提供的内容证据，trace 可核对真实模型请求/响应与最终选择，不以来源名单或关键词数量解释选择

### Requirement: 同一事件的独立内容保留参与策展资格

系统 SHALL 继续按文章内容识别副本、转载、镜像及没有实质独立增量的近重复；事件、主题或实体相同不构成重复。Agent SHALL 考虑实质独立报道、解释和不同分析是否增加阅读价值，不按政治观点方向过滤。

#### Scenario: PAT-V11-04 同一事件的不同观点可以共同入选
- **GIVEN** 一篇独立事实报道与一篇对同一事件的原创分析均通过内容去重、语义价值判断和用户约束；另有其中一篇的复制/转载版本
- **WHEN** 系统形成 Daily Issue
- **THEN** 两篇独立文章保持资格且可共同占据两个位置，各有自身归属和贡献理由；复制/转载版本只保留一个文章位置，共享事件本身不触发拒绝

### Requirement: 语义决定必须通过版本化结构契约校验

系统 SHALL 记录语义契约版本，并严格验证每个候选 ID、决定和判断字段；结果只能引用本次允许输入中的候选，且每个候选有一个明确决定。未知版本、缺项、重复/未知 ID 或非法字段值 SHALL 作为无效语义响应处理。模型不能写入候选 URL、来源事实、核验状态、度量值或 Daily Issue 完成状态。

#### Scenario: PAT-V11-05 无效或越权模型响应不能改变交付事实
- **GIVEN** 语义响应分别包含未知契约版本、遗漏/重复/未知候选 ID、非法判断值，或试图添加 URL/来源/全文状态等权威字段
- **WHEN** 系统验证并处理这些响应
- **THEN** 响应被拒绝或越权字段被明确阻断，不能引入新文章、改写核验事实或把 Issue 标为 COMPLETE；无效契约响应遵守 PAT-V11-08 的诚实失败规则

### Requirement: 必需语义能力不可用时诚实失败

V1.1 SHALL 复用用户现有模型/提供商配置，不引入未经批准的新付费服务。缺少配置、提供商失败或无效语义响应 SHALL 在 attempt/trace 中可观察，保留旧交付、历史及进度；既有有界重试仍生效。V1.1 默认 SHALL 不自动使用确定性编辑降级路径，不得将未执行模型判断的尝试标为 Agent 策展成功。

#### Scenario: PAT-V11-08 能力不可用或响应无效不会伪装成功
- **GIVEN** 已有归档和阅读进度，本次语义能力分别缺少配置、超时/失败或返回无效结构
- **WHEN** 用户启动 collection 或 scheduled attempt
- **THEN** 本次记录可观察失败原因与语义运行状态，不产生未经语义判断的新交付，不声称 Agent 成功或新 Issue COMPLETE；旧内容及进度保留，自动重试不超过 V1 上限

### Requirement: 每篇新交付文章保留简短编辑理由

系统 SHALL 为每篇 V1.1 新交付文章保留契约版本、关联语义决定、主题适配与占用阅读位置的简短理由，以及 reporting、analysis、explanation 或 perspective 等贡献类型。用户 SHALL 能从可选详情或 trace 查看；默认阅读面无须增加常驻标签。既有 V1 文章不要求补造 Agent 理由。

#### Scenario: PAT-V11-09 编辑理由随文章保留且可检查
- **GIVEN** 一次真实语义策展已交付文章
- **WHEN** 用户打开可选详情/trace，然后关闭并重新打开 Reader 或重启服务
- **THEN** 相同文章仍可核对原编辑理由、贡献类型和决定版本；理由不包含未提供的来源事实，不改写原归属；原 V1 文章可以没有该新增理由

### Requirement: 最终交付由硬性约束和实际文章决定

系统 SHALL 只从通过客观核验且得到有效语义批准的新增候选中形成 Issue，继续满足保存的主题、精确篇数、难度及 70%–100% 阅读时长目标（100% 硬上限）。确定性软件 SHALL 计算词数、时长、难度与实际履约，不接受模型的 COMPLETE 断言。供给不足时明确 PARTIAL/NOT_DELIVERED，不用模型否决或不合格文章补位。

#### Scenario: PAT-V11-10 语义选择不削弱 V1 履约约束
- **GIVEN** 模型推荐中存在超预算、难度不符或不足目标数量的组合，并存在被模型拒绝但能凑足篇数的候选
- **WHEN** 系统完成选择和 Daily Issue 计算
- **THEN** 只交付客观合格且有效批准的文章，超过硬上限的组合不交付；实际未满足篇数/主题/难度/时长目标时显示 PARTIAL 或 NOT_DELIVERED 及缺项，不因模型断言或关键词补位标 COMPLETE
