## 3. 检索 API 与模型边界

- [ ] 3.1 实现 `POST /api/retrieve` 的请求解析、空值/500 字符/请求体校验和稳定错误映射；通过 400、成功和超长输入集成测试验证
- [ ] 3.2 实现不暴露给客户端的 `ExpressionProvider` 接口和 DeepSeek adapter，隔离鉴权、模型名、参数、上游响应和错误格式；通过 mock provider contract test 验证替换 adapter 不影响领域契约
- [ ] 3.3 编写版本化系统 prompt，明确意图推断、噪声分离、自然表达优先、英文-only、候选上限和输入隔离；通过 prompt fixture 评测确认示例和规则覆盖规格场景
- [ ] 3.4 实现模型响应解析、schema 校验、字段长度/枚举约束和最多一次受限修复请求；通过非法 JSON、未知字段、错误枚举和修复失败测试验证半成品不会进入客户端
- [ ] 3.5 实现上游超时、429、网络失败、不可用结果和内部错误到应用错误码的映射；通过模拟各类失败验证客户端可重试且不泄露内部响应
- [ ] 3.6 添加基础请求限流、上游超时、成本保护和最小非敏感日志；通过限流测试和日志审查验证原始输入、API key 和完整模型响应不会被记录

## 4. 主检索界面

- [ ] 4.1 实现单页输入 surface，包含自动聚焦、多行编辑、500 字符限制、空值提示、Enter 提交和 Shift+Enter 换行；通过键盘交互测试验证 composition 状态不会误提交
- [ ] 4.2 实现 `idle`、`editing`、`submitting`、成功、澄清、无匹配和服务错误状态机；通过状态转移测试验证重复提交被阻止、错误保留输入且 Retry 可恢复
- [ ] 4.3 实现固定层级的结果 renderer：Best match、Useful expressions、Natural version 和条件性 Explanation；通过契约 fixture 验证最多 3 个替代项、空解释不占位、中文不被自动渲染
- [ ] 4.4 实现表达、替代项和自然句的复制动作及可访问的成功反馈；通过剪贴板 mock 和键盘测试验证复制内容准确且不改变当前页面状态
- [ ] 4.5 实现保存、主题切换、焦点环、live region、语义标签和 reduced-motion 支持；通过 axe 检查、人工 Tab 流程和深浅色主题截图验证
